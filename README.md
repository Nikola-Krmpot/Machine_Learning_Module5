# Machine_Learning_Module5
Fifth module of the Machine Learning course

Author: Nikola Krmpot

This project is meant to explore multiple algorithms in Machine Learning.
Dataset used here is cars.csv.
Algorithms compared are: LinearRegression, DecisitionTreeRegressor, RandomForestRegressor and GradientBoostingRegressor.

For the purpose of this project, I picked the Random Forest algorithm because when we look at the metrics, it is the best out of these 4.
